# MOE provenance

Taiwan Ministry of Education (MOE) is the authority for reference content.

| Dataset | Source | License | Local path after fetch |
|---|---|---|---|
| Stroke-order catalog + XML | `https://stroke-order.learningweb.moe.edu.tw/` | CC BY-NC-ND 3.0 TW | `tools/data/moe/U+*.xml` |
| Converted stroke JSON | generated by `tools/fetch_moe.py` (stdlib only) | same, technical conversion only | `app/src/main/assets/stroke_order/` |
| Concise/revised dictionary entries | `https://dict.concised.moe.edu.tw/`, `https://dict.revised.moe.edu.tw/` | CC BY-NC-ND 3.0 TW (see site terms) | `tools/data/moe-dict/` |

Rules:

- Keep `source`, `url`, `license`, `sha256`, and fetch date per dataset in
  `app/src/main/assets/*/manifest.json`.
- Never commit originals or conversions (see `.gitignore`). Commit only
  manifests and checksums.
- Never mix PRC and Taiwan stroke orders or lexical norms without explicit
  provenance.
- Attribution is shown in-app on the stroke viewer and dictionary source
  dialog at all times.
